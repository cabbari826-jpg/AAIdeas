# Açar Söz Studio: инструкция

Программа для Windows, чтобы делать новые уровни кроссворда без Claude:
сгенерировать уровни, быстро просмотреть их с готовыми ответами, поправить подсказки
и выпустить игрокам. Всё бесплатно: работает через ваш GitHub, никаких платных сервисов.

## 1. Установка (один раз)

1. Скачайте `acar-soz-studio.exe`. Свежая версия всегда лежит тут:
   https://github.com/cabbari826-jpg/AAIdeas/releases/download/studio/acar-soz-studio.exe
2. Положите файл куда удобно, например на рабочий стол, и запустите двойным щелчком.
   Устанавливать ничего не нужно.
3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер»,
   нажмите «Подробнее», затем «Выполнить в любом случае». Так бывает с любой программой
   без платной цифровой подписи.

## 2. Токен GitHub (один раз, 5 минут)

Токен это пароль только для этой программы. Он хранится на вашем компьютере
(в папке `%APPDATA%\AcarSozStudio`) и больше никуда не отправляется, кроме GitHub.

1. Откройте https://github.com/settings/personal-access-tokens/new и войдите в GitHub.
2. **Token name**: `Açar Söz Studio`. **Expiration**: 1 год (через год сделайте новый так же).
3. **Repository access**: «Only select repositories», выберите `AAIdeas`.
4. **Permissions → Repository permissions**:
   - **Contents**: Read and write (чтобы выпускать уровни);
   - **Actions**: Read and write (чтобы запускать генерацию в облаке).
5. Нажмите **Generate token** и скопируйте токен (начинается с `github_pat_`).
6. В программе откройте вкладку **Настройки**, вставьте токен, нажмите **Проверить**.
   Внизу должно появиться зелёное «Токен работает». Нажмите **Сохранить**.

## 3. Сделать новые уровни: вкладка «Генерация»

1. Выберите **пак** (например `az-starter` для основного, `az-novruz` для Новруза).
2. Укажите, **сколько уровней** нужно.
3. Нажмите **Сгенерировать в облаке**. Через 2–5 минут уровни сами откроются на вкладке «Ревью».

Есть и второй способ, **На этом компьютере**: быстрее и без интернета, но нужен Python
(https://www.python.org/downloads/, при установке поставьте галочку «Add python.exe to PATH»).
Один раз нажмите **Скачать файлы генератора**, потом **Сгенерировать здесь**.
Файлы генератора скачивайте заново, когда в GitHub добавились новые слова.

Генератор ставит в сетку только слова, у которых уже есть три подсказки, и не повторяет
слова, которые уже есть в игре. Если слов не хватило, уровней получится меньше:
значит, в пак пора добавить новые слова.

## 4. Просмотр: вкладка «Ревью»

Уровень показан как у игрока, но все ответы уже вписаны.

- Слева список уровней: `•` не просмотрен, `✓` хорошо, `✗` отклонён. `⛔` ошибки, `⚠` замечания.
  Галочка «только новые» прячет уровни, которые уже есть в игре.
- В середине сетка. Наведите мышь на подсказку, чтобы увидеть все три её варианта.
  Сверху можно переключить, какие подсказки видны в клетках: сложные, средние или лёгкие.
- Справа **Проблемы** (нажмите на строку, и слово подсветится) и **Слова и подсказки**.
  Нажмите на слово, чтобы исправить его подсказки. Число рядом показывает длину:
  больше 16 знаков в клетку не влезет.
- Кнопка **Викисловарь ↗** открывает слово в словаре только для справки.
  Подсказку пишите своими словами, текст из словаря не копируйте.

Клавиши: **Enter** хорошо и дальше, **Delete** отклонить и дальше, **← →** листать,
**1 2 3** какие подсказки показывать в сетке.

Что программа проверяет сама:
- ⛔ слово или подсказка уже есть в другом уровне или паке (повторы);
- ⛔ у слова нет подсказки или стоит «?»; две одинаковые подсказки у одного слова;
- ⛔ буквы на пересечении не совпадают, слово выходит за сетку, неверное ключевое слово;
- ⚠ подсказка слишком длинная или мелкая для клетки на маленьком телефоне;
- ⚠ подсказка содержит само слово; слишком много слов из 2–3 букв.

Всё сохраняется само. Черновики лежат в `%APPDATA%\AcarSozStudio\drafts`
(кнопка «📂 Открыть» → «Последние черновики»).

## 5. Выпуск: вкладка «Выпуск»

Выходят только уровни с отметкой **✓ Хорошо**. Уровни с ошибками выпустить нельзя.

1. **Выпустить в игру**: уровни добавляются в приложение. GitHub сам собирает
   новую версию за 10–20 минут, и телефон предлагает обновиться. Подходит, пока
   в приложении до ~100 уровней.
2. **Выложить как скачиваемый пак**: уровни выкладываются отдельным файлом
   (релиз `packs` на GitHub), чтобы игроки скачивали их, когда пройдут встроенные уровни.
   Сама игра научится скачивать такие паки отдельной доработкой.

Если уровень, который уже в игре, отметить **✗**, при выпуске он будет убран из игры.
Исправленные подсказки старых уровней тоже уходят при выпуске.

## Если что-то не так

- Внизу окна красная строка с текстом ошибки. Подробности на вкладке «Генерация» → «Журнал».
- «GitHub не принял токен»: токен истёк или скопирован не полностью. Сделайте новый (раздел 2).
- «У токена нет нужного права»: проверьте права Contents и Actions (раздел 2).
- Генерация в облаке: ход работы виден на https://github.com/cabbari826-jpg/AAIdeas/actions

### Для разработчика

Rust + egui. Сборка под Windows: `cargo build --release` на Windows или
`cargo build --release --target x86_64-pc-windows-gnu` на Linux (нужен mingw-w64).
Workflow `.github/workflows/crossword-studio.yml` собирает .exe и кладёт его в релиз `studio`.
Тесты: `cargo test`. Тест выпуска с поддельным GitHub: запустить
`python3 tools/fake_github.py 8765 crossword-app/app/src/main/assets/packs/az-kimya.json=<копия пака>`
и `ACAR_STUDIO_TEST_API=http://127.0.0.1:8765 cargo test publish_against`.

Генератор: `crossword-app/tools/make_levels.py PACK COUNT [SEED] --out FILE.json`,
в облаке `.github/workflows/crossword-levels.yml` (inputs `pack`, `count`, `seed`), artifact `levels-<pack>`.
Скачиваемые паки: копия в `crossword-app/content/downloadable/<id>.json` (генератор не повторяет их слова)
и ассеты релиза `packs`: `<id>.json` + `index.json`
(`{"formatVersion":1,"packs":[{"packId","title","levels","contentVersion","file","bytes","after"}]}`).
