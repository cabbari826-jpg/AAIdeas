# Черновой генератор

`fill.py ROWS COLS SEED [TRIES] [DENSITY]` перебирает случайные раскладки клеток-подсказок
(верхняя строка и левый столбец всегда подсказки) и заполняет их словами из `words.py`
поиском с возвратом. Оценка: больше букв и пересечений, меньше двухбуквенных слов.

Уровни пака собраны так: `python3 fill.py 8 7 12 3000 0.2` и `python3 fill.py 8 7 14 3000 0.2`,
затем подсказки отредактированы вручную. Это прототип, а не будущий движок из диздока.

`USE_DICT=1 python3 fill.py ...` добавляет к `words.py` большой список слов из
`dict/candidates_az.txt` (у этих слов подсказка `?`, её надо написать). Пока без
частотного фильтра генератор охотно берёт редкие слова (OSURAQ, RİAS), поэтому для
готовых уровней словарь стоит сначала сократить до частых слов.

## Новые уровни без повторов (gen_pack.py)

`python3 gen_pack.py COUNT SEED` берёт банк слов (`words.py`, `words_hard.py`, `words_more.py`),
выкидывает все ответы и ключевые слова, которые уже есть в паке (и слова из `SKIP=...`),
ставит не больше одного слова из 2 букв и трёх из 3 букв на уровень и пишет `out_levels.json`.
Потом `python3 apply_tiers.py review.md` дописывает уровни в пак с тремя подсказками из
`clue_tiers.py`, `clue_tiers2.py`, `words_more.py` и падает, если подсказки нет или текст
подсказки повторяется. Уровни 5–25 собраны так:
`SKIP=<синонимы и слова для тематических паков> TRIES=400 python3 gen_pack.py 21 13`.
