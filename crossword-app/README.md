# Krossvord — прототип

Азербайджанский скандинавский кроссворд для Android (Kotlin + Jetpack Compose).
Прототип: 2 уровня, ввод-анаграмма (буквы слова разбросаны по двум колонкам слева и двум справа, слово собирается по очереди), плитки и полная клавиатура как варианты в настройках; лишние буквы и скрытие подсказок включаются в настройках, подсказки, сохранение прогресса,
заглушки рекламы и флаг премиума.

> По решению из `docs/00_Analysis_and_Recommendation.md` (п. 6) у приложения будет свой репозиторий.
> Пока доступа к нему нет, код лежит здесь, в папке `crossword-app/`, и переносится целиком.

## Как запустить
1. Установить Android Studio, открыть папку `crossword-app/`.
2. Дождаться синхронизации Gradle, нажать Run (телефон по USB с включённой отладкой или эмулятор).

Из командной строки:
```
./gradlew testDebugUnitTest      # логика, словарь, правила рекламы
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest -Proborazzi.test.record=true   # скриншоты в app/build/outputs/roborazzi
```

## Что внутри
| Путь | Что |
|---|---|
| `model/AzText.kt` | Нормализация азербайджанского текста `az-v1`: NFC, верхний регистр по правилам az (i→İ, ı→I), 32 буквы, одна буква = одна клетка |
| `model/Puzzle.kt` | Формат пака (JSON, `formatVersion: 1`) и проверка уровня: пересечения, дубли, клетки-подсказки (не больше одной → и одной ↓) |
| `model/GameState.kt` | Вся игровая логика без Android: выбор слова, ввод, стирание, бесплатная очистка слова, подсказка-буква |
| `ui/` | Экраны: главная, уровни, кроссворд, настройки; цвета клеток как токены темы (светлая и тёмная) |
| `monetization/Ads.kt` | Интерфейс `AdService` + заглушка-диалог; `AdPolicy`: межстраничная реклама только после уровня, не после первого, не чаще раза в 2 уровня, никогда для премиума |
| `monetization/Premium.kt` | `PremiumManager`: локальный флаг. Потом заменяется на Google Play Billing |
| `assets/packs/az-starter.json` | Первый пак |
| `tools/` | Черновой генератор сетки (Python) и список слов, из которого собраны уровни |

## Формат скандинавского уровня
Подсказка стоит в клетке `(clueRow, clueCol)`. Для `ACROSS` ответ начинается справа от неё,
для `DOWN` — снизу. Клетки без букв и без подсказок рисуются пустыми.

## Контент
Все 30 слов и подсказок — **черновик Claude** (`"source": "claude-draft"`, `"status": "candidate"`),
не взяты из словарей. Перед релизом их проверяет владелец, а слова для следующих паков берутся
из открытых словарей с записью источника и лицензии (см. `content/SOURCES.md`).

## Чего пока нет
AdMob и окно согласия UMP, Google Play Billing, Room, скачиваемые паки, звуки и анимации,
стрелки-«уголки» скандинавского формата, настоящий генератор с оценкой качества сетки.
