# Как делать новые уровни самому (без Claude)

Генератор не придумывает слова и подсказки. Он берёт готовые слова с тремя подсказками
из папки `crossword-app/content/words/` и раскладывает их по сетке. Каждое слово
используется только один раз во всех паках, подсказки тоже не повторяются. Когда слова
в списке кончаются, генератор так и пишет: «добавьте слова».

## Где лежат слова

`crossword-app/content/words/` — обычные текстовые файлы, их можно открыть Блокнотом:

| Файл | Для чего |
|---|---|
| `umumi*.txt` | общие слова: основной пак «Başlanğıc» и «добивка» сетки в тематических паках |
| `az-novruz.txt`, `az-qadinlar.txt`, … | слова праздничных паков (по одному файлу на праздник) |
| `az-cografiya.txt`, `az-tarix.txt`, … | тематические паки |
| `az-usaq.txt` | детский пак |

Одна строка — одно слово:

```
SƏMƏNİ | Cücərmiş buğda | Xonçanın yaşılı | Bayram yaşıllığı
```

Сначала слово, потом через `|` три подсказки: сложная (её видят сразу), средняя
(бесплатная) и лёгкая (за рекламу). Каждая подсказка не длиннее 16 букв, а в ней самой
не должно быть ответа. Строки с `#` — это комментарии. Строка `# title: Novruz` задаёт
название нового пака.

Проверка `check_words.py` сама найдёт ошибки: длинную подсказку, слово, которое уже есть
в другом файле, или подсказку, которая уже встречается у другого слова. Она назовёт файл
и номер строки.

## Вариант 1. На компьютере (Windows)

Один раз:
1. Установите Python с https://www.python.org/downloads/ . В первом окне установщика
   поставьте галочку **Add python.exe to PATH**.
2. Скачайте репозиторий: на GitHub нажмите **Code → Download ZIP** и распакуйте архив.
   Можно и через GitHub Desktop, тогда потом удобнее отправлять изменения.

Каждый раз:
1. Откройте папку `crossword-app` и дважды щёлкните **`make-levels.bat`**.
2. Введите пак (например `az-starter`) и число уровней (например `10`).
3. Скрипт проверит слова, соберёт уровни, проверит повторы во всех паках и запишет
   `clues-for-review.md`, лист подсказок для проверки.

Можно и одной командой из командной строки: `make-levels.bat az-starter 10`.
Третье число (`make-levels.bat az-starter 10 7`) даёт другие сетки из тех же слов.

Уровни сохраняются в `app/src/main/assets/packs/<пак>.json`. Если их отправить на ветку
прототипа (GitHub Desktop: Commit → Push), GitHub сам соберёт приложение, и телефон
получит обновление.

## Вариант 2. С телефона, кнопкой на GitHub

1. Откройте репозиторий на GitHub, вкладку **Actions**, слева **crossword-levels**.
2. Нажмите **Run workflow**. Укажите пак и число уровней.
3. Если поставить галочку **publish**, новые уровни сохранятся в приложении, а GitHub
   соберёт и выпустит обновление. Телефон предложит его установить, как обычно.
   Без галочки просто получится файл для просмотра (внизу страницы запуска, в блоке
   **Artifacts**: пак, отчёт о повторах и лист подсказок).

## Какие паки есть

- `az-starter` — основной пак «Başlanğıc»
- `az-cografiya`, `az-tarix`, `az-edebiyyat`, `az-musiqi`, `az-kimya` — темы
- `az-usaq` — детский
- `az-mini` — ежедневный мини-кроссворд (слова тут могут повторять другие паки)
- праздничные паки (видны в игре только около праздника): `az-yeniil`, `az-novruz`,
  `az-qadinlar` (8 Mart), `az-qelebe` (9 May), `az-musteqillik` (28 May), `az-qurtulus`
  (15 İyun), `az-ordu` (26 İyun), `az-zefer` (8 Noyabr), `az-bayraq` (9 Noyabr),
  `az-hemreylik` (31 Dekabr), `az-ramazan`, `az-qurban`

Новый пак появится, если создать файл `content/words/<id>.txt` со строкой `# title: Название`
и запустить генератор с этим id. Чтобы новый праздничный пак открывался только в
свои дни, его надо добавить в `Holidays.kt`. Это уже правка кода.

## Если что-то пошло не так

- **«Stopped after N new levels»**: в списке кончились свободные слова. Добавьте строк
  в `content/words/<пак>.txt`, для основного пака — в `umumi*.txt`.
- **«clue longer than 16 letters»** или **«the clue gives the answer away»**:
  исправьте названную строку.
- **«clue … used for …»**: две разные строки с одинаковой подсказкой. Поменяйте одну.
